О проекте

Немного о нас

FlaskSite — небольшой учебный веб-проект, созданный с использованием Python, Flask, HTML и CSS.

🐍

Python

Python используется для серверной части приложения и обработки запросов пользователей.

⚙️

Flask

Flask связывает страницы сайта, маршруты и серверную логику приложения.

🎨

HTML & CSS

HTML отвечает за структуру страниц, а CSS — за их внешний вид и оформление.

Наша цель

Учиться, создавая

Этот проект создан для изучения основ веб-разработки на Python и понимания того, как браузер взаимодействует с сервером.
